# DuckGame-College-Project

This repo contains a project made in October of 2024 for the Universidad de Buenos Aires, where the goal was to make a game as similar to [DuckGame](https://store.steampowered.com/app/312530/Duck_Game/) in C++ within 2 months.
This work was a group project, with contributions from:
* [IralaElbio](https://github.com/IralaElbio) - Server and game logic
* [cpared](https://github.com/cpared) - Lobby logic and graphics, audio processing

I was tasked with graphics management during gameplay, camera logic and support in developing game logic with Elbio.

**Disclaimer:** this project was made for educational purposes and not intended for sale or distribution. Any artwork used was for our aim to look as close to the real game we were trying to emulate, and since non of us is an artist, all artwork used was taken from the web and edited accordingly. All art credit belongs to [Landon Podbielski](https://store.steampowered.com/search/?developer=Landon%20Podbielski).
